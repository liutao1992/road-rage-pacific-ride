# 海岸狂飙 · ROAD RAGE

[立即游玩](https://liutao1992.github.io/road-rage-pacific-ride/)

原创 3D 浏览器摩托游戏，致敬《暴力摩托》的公路竞速与战斗玩法。包含落日海岸、红杉山道和钢铁边缘三条原创路线，支持键盘和触屏。

| 按键 | 操作 |
| --- | --- |
| W / ↑ | 加速 |
| S / ↓ | 刹车 |
| A / D / ← / → | 转向 |
| 空格 + 转向 | 漂移，松开结算积分并补充氮气 |
| Shift | 氮气加速 |
| J / K | 左右挥拳 / 铁链攻击 |
| Q / E | 左右踢击推开对手 |
| L 按住 | 格挡，消耗体力 |
| V 按住 | 后视，观察巡警 |
| C | 切换镜头 |
| P / Esc | 暂停与继续 |
| R | 重新发车 |
| H | 完整操作指南 |
| M / B / F | 总声音 / 背景音乐 / 全屏 |

推荐首次选择“轻松兜风”。手机建议横屏，屏幕按钮支持多指同时操作。最佳成绩保存在当前浏览器。

纯静态站点，所有运行依赖均包含在仓库中。需要支持 WebGL 的现代浏览器。可用 `python3 -m http.server 8000` 本地预览。

GitHub Pages 使用 `main` 分支根目录作为发布源，`.nojekyll` 保证按原样提供静态文件。

游戏模型、纹理、赛道为原创程序生成内容，并非原版资源的精确复刻。Three.js r170 按 MIT 许可使用，见 [许可文件](vendor/LICENSE.three.txt)。

## 背景音乐

点击开始后自动播放原创器乐曲《Pacific Rebellion》，144 BPM、32 小节、约 53.33 秒循环。B 单独切换配乐，M 静音全部声音；也可以使用右上角 BGM 按钮。暂停时自动降低配乐音量，切换到其他标签页时暂停音频。

曲谱与合成脚本：[scripts/generate-soundtrack.mjs](scripts/generate-soundtrack.mjs)。脚本输出可重建的 WAV 中间文件到 `dist/audio/`；发布资源为 [audio/pacific-rebellion.mp3](audio/pacific-rebellion.mp3)，未使用原版游戏音轨。

## 2.0 追缉与混战更新

- 持续超速、逆行和命中对手会提高通缉。达到阈值后警用摩托从后方追来，高通缉会呼叫第二辆巡警并设置路障。警笛音量随距离变化，小地图显示红蓝警察标记。
- 巡警靠近且车速低于 10 m/s 时开始拘捕，保持约 2.8 秒即被捕。提前加速离开能取消拘捕。与全部追警拉开 58 米以上并保持高速 5 秒，或击退全部巡警，可脱逃并获得 20 氮气。
- 路障提前 380 米提示，中央、左侧、右侧三种缺口轮换。没有碰撞地穿过缺口获得 12 氮气。
- 普通攻击、踢击和格挡消耗体力，松开格挡、停手后恢复。近身目标会显示血条与攻击方向。铁链有 8 次命中耐久；踢击能把对手推向一旁。连击和击倒会显示反馈。
- CHAIN / NITRO / REPAIR 光环分别提供铁链、40 氮气、28 车况。尾流跟车可获得额外氮气。
- 干净结束漂移获得短时自动加速，碰撞和冲出路面会取消当前漂移奖励。高速重撞会倒地，自动扶车期间失去时间。
- 调整了对手速度和加速，氮气耗尽时平顺减速。2.0 最佳成绩使用单独的记录键，旧记录仍保留在浏览器中。

触屏新增“格挡”“拳击/踢击切换”和“后视”；左右攻击按钮使用所选动作。手机建议横屏。

## 验证

无需安装依赖，执行 `npm test` 运行 29 项行为测试，`npm run check` 检查语法。`npm run preview` 在 8000 端口启动静态预览。浏览器验证记录见 [VERIFICATION.md](VERIFICATION.md)。
